# LU Decomposition 

## AIM:
To write a program to find the LU Decomposition of a matrix.

## Equipments Required:
1. Hardware – PCs
2. Anaconda – Python 3.7 Installation / Moodle-Code Runner

## Algorithm
1. Import the numpy module to use the built-in functions for calculation and lu function from sciply.linalg
2. Read the list and assign in np.array()
3. Using the lu() and lu_factor() and lu_solve(), we can find the solutions.
4. End the program
